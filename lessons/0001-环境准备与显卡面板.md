# 0001 环境准备与显卡面板(阶段 0.1~0.2)

## 三问(阶段动机)

**终极目标:** 让你能独立部署、监控、调优一个 LLM 推理服务。

```
✅ 0.环境准备(你在这里)  ⬜ 1.跑起服务  ⬜ 2.监控指标  ⬜ 3.调参  ⬜ 4.压测  ⬜ 5.量化与K8s
```

- **这阶段干嘛的:** 你的 Mac 没有 NVIDIA 显卡,vLLM 只能在 NVIDIA 上跑,所以租一台云 GPU 当学习机,并学会看显卡的"仪表盘"。
- **什么需求逼的:** 推理服务出问题时,九成线索在显卡面板上——不看它两眼一抹黑。
- **解决了什么麻烦:** 以后服务慢了/挂了,先看面板就能判断个大方向,不用瞎猜。

## 全链路一览

```
你的 Mac(只有键盘和屏幕,负责发号施令)
   │  ssh gpu(免密登录)
   ▼
云上的 GPU 机器(真正干活的地方:装着 RTX 4090)
   │  nvidia-smi(显卡的仪表盘)
   ▼
显卡状态:型号 / 显存用了多少 / 忙不忙
```

## 跟着数据走

在服务器上敲 `nvidia-smi`,出来一张表,重点看三格:

1. `0 MiB / 24564 MiB` —— **显存**。像停车场的车位:现在空着(0 辆),总共 24G 车位。等模型上车,这里先被"权重"停走一块,剩下的给"KV cache"包场。
2. `GPU-Util 0%` —— **忙不忙**。像工厂机器的开工率:0% = 没活干;持续 100% = 机器连轴转,该加机器了。
3. 最下面 `Processes` —— **谁占着车位**。服务起不来时先看这里:经常有上次的"僵尸进程"赖着不走,把车位占光了。

## 新技术点四要素

**CUDA(显卡计算的"通用语言")**
- 名字:Compute Unified Device Architecture,英伟达的 GPU 计算平台
- 作用:显卡原本是画游戏画面的,CUDA 让它能算数学。LLM 推理全是矩阵运算,全靠它。AMD 和 Mac 的芯片不会这门语言,所以 vLLM 跑不了
- 参数:无;记住报错常客 `CUDA out of memory` = 显存车位满了
- 用法:对我们透明,装软件时选对 CUDA 版本就行(机器驱动支持到 13.0,向下兼容)

**SSH 免密登录(给服务器配钥匙)**
- 名字:Secure Shell + 公钥认证
- 作用:在自己 Mac 上操控远端机器。免密 = 把你 Mac 的"钥匙印模"(公钥)存在服务器的锁匠铺(`authorized_keys`),以后开门不用报密码
- 参数:`ssh-keygen -t ed25519` 配钥匙;`ssh-copy-id` 送钥匙上门;`~/.ssh/config` 写 `Host gpu` 起绰号
- 用法:本项目挂载点——`ssh gpu` 直达学习机

## 关键顿悟

- **报成功 ≠ 真成功。** 任何安装/启动,最后都要亲眼验证(`docker --version`、`ssh gpu` 能进),别信"看起来装完了"。
- **关机不计费。** 租的机器不用时在控制台关机,这是省钱的核心习惯。
- **磁盘只有 30G。** 这台机器的唯一短板:一个 7B 模型就要 15G,别囤模型。
